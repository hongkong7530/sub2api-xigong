## 本轮发现与处理

- 首次前端命令因 PowerShell 将 pnpm 的 stderr 警告视为 `NativeCommandError` 而中止，没有到达源码构建；改为直接进程调用后完整构建通过。保留依赖工具警告，不降级业务断言。
- 开发说明原 Node 20+ 与锁定依赖的 Node >=22 要求冲突，已统一推荐 Docker 同款 Node 24。
- 恢复预算文案由「逐条 5 秒」纠正为「每轮金额回放阶段共享最多 5 秒/父剩余预算一半」，源码未改。
- 原生日志经过 PowerShell 重定向使用 UTF-16；最终统计按实际编码解析，未把空解析结果当作零测试通过。
- 凭据格式扫描命中 10 处既有公开测试私钥标记，逐项确认是相同占位且邻近无长密钥材料；未把测试文件整体加入不受检查的发布白名单。
- 可疑长赋值另复核为认证模式标识、Vue 事件绑定和含示例标记的既有公开 URL，不是本次发现的真实生产秘密。扫描有模式局限，不能称为完整安全审计。
