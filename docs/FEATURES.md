# 定制功能与上游差异

本文描述**源码中实现的能力**，不意味着演示站已启用全部功能，也不表示完整生产验收。

## 上游基础

保留 Sub2API 的账号池、OAuth/API Key、兼容协议网关、鉴权、订阅与余额计费、支付和后台管理。第三方模型是否可用取决于自己的账号授权与服务商政策。

## 首页与控制台

- 沉浸式首页、壁纸轮播、液态玻璃折射、粒子标题与氛围文字。
- 管理员配置外观、主题、动态效果、电脑/手机图片及独立焦点。
- 手机端布局与监控阅读表面，减少动态及部分减少透明度回退。
- 文档、公告、荣誉站点与媒体上传；站点链接可自动读取元信息和尝试真实截图，失败支持手动上传。
- 外部一言和本地离线句池。外部服务不可用不保证远程内容更新。

## 渠道状态与模型广场

- 结合真实请求事实与主动探测，展示状态、历史、首字耗时、输出速度和观察来源。
- 首页匿名状态使用专用公开字段，管理详情仍受权限控制；配置公开范围时须评估聚合数据泄露。
- 公开分组自动配给监控与广场渠道，保护人工价卡与既有配置；自动化不是免费的上游调用。
- 分组白名单、模型目录、自定义价格和长上下文阈值。
- Fast/Flex/Ultrafast 策略及用量徽标；服务档位与真实上游确认不同，价格倍率不等于速度倍率，支持模型/价格必须以当前提供商说明及自己的配置为准。

## 用户与用量

- 分组分类与 API 密钥夹。
- Key 级提示词模板，支持管理员模板与个人输入；模板不保证模型输出、不授予越权用途。
- 用量、费用、缓存和服务档位展示。缓存命中率以缓存读取除以未缓存输入加缓存总量，缓存创建参与分母、输出不参与。
- 输出速率基于可验证的完整流事件区间和总输出 Token，可能包含推理；不是纯可见文字速度，缺少信息时保持未知。
- 高速用量的有限装饰动效，遵循动态关闭与减少动态偏好。

## 集群增强

- 入口/控制器/工作节点/迁移器角色化启动。
- mTLS 节点连接、准入与遥测、容量控制、连接池预算和控制台。
- 幂等费用事件、原子结算与本地受保护恢复槽。
- 存储预览和有界操作保护；历史迁移保留，不复制演示站真实拓扑。

详见 [架构](ARCHITECTURE.md)。多实例不保证线性扩展，跨区域数据库延迟可能抵消吞吐收益。

## 当前不包含

- 已退役的独立 Devin 集成和内嵌生图台页面；历史账务兼容字段/迁移不等于仍开放旧功能。
- 演示站账号池、支付密钥、生产数据库、运营数据或公开管理员凭据。
- 任何无需配置即可保证可用的第三方模型服务。
- 对全浏览器恒定 60fps、全站 WCAG、全协议无故障或完整安全审计的声明。

## 与演示站的差别

源码快照包含最近的本地修正，站点有自己的运行配置与发布节奏。演示站截图证明页面实际渲染，不证明公开源码对应的每项后端功能已在生产运行。开源发布不执行生产迁移或重启。
