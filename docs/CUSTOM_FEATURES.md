更新日期：2026-10-26。源码版本：`0.2.18-custom-cluster-v3`，整合上游 v0.2.18。

## 01. 沉浸式首页、液态玻璃与移动端适配

- **功能**：壁纸轮播、粒子品牌标题、氛围文字、液态玻璃折射、首页与控制台统一主题；桌面和手机采用对应布局。
- **使用**：管理员在站点内容/外观入口选择首页模式和主题；用户可关闭动态效果。系统减少动态偏好会停止相应装饰，部分减少透明度场景使用实底阅读面。
- **细节**：手机监控采用高对比表面，状态同时使用文字、颜色和形状区分；玻璃效果不用于掩盖失败或未知状态。装饰动画与业务数据刷新互相独立。
- **实现**：`frontend/src/features/home/`、`frontend/src/features/appearance/`、`frontend/src/components/layout/`。
- **边界**：真实折射依赖浏览器/GPU，不承诺全设备恒定 60fps、全部浏览器效果一致或全站无障碍认证。

## 02. 站点内容、文档、公告与荣誉站点

- **功能**：管理员维护站点介绍、公开文档、公告、荣誉站点及首页展示内容，不必改代码重建文本。
- **使用**：通过站点内容和文档管理页面编辑；保存采用版本比较，过期草稿发生冲突时不能静默覆盖新内容。
- **细节**：荣誉站点的 HTTPS 地址可用于读取名称、描述、图标或截图；读取失败可以手工填写和上传。外部取图有公网地址检查和资源限制。
- **实现**：`frontend/src/views/admin/SiteContentView.vue`、`DocsManageView.vue`、`frontend/src/features/docs/`，后端 `site_*` 服务与仓储。
- **边界**：自动截图/图标会涉及第三方服务，管理员应知悉目标链接的外发；抓取失败不伪造站点 Logo 或截图。

## 03. 自托管图片、分设备壁纸与焦点

- **功能**：站点图片上传、电脑/手机独立壁纸和焦点定位，支持本地内置资源回退。
- **细节**：上传接受 JPEG/PNG，单图上限 8 MiB、1600 万像素，服务端解码重编码；内容寻址去重，站点媒体有 256 张/256 MiB 共享配额。手机图片未配置时依次回退桌面图与内置图。
- **兼容**：旧客户端省略字段保留既有配置，显式空串表示清除；上传乱序、卸载和设备切换不应覆盖其他草稿。
- **实现**：`frontend/src/features/appearance/AssetInput.vue`、`WallpaperEditor.vue`、`frontend/src/features/home/wallpaperSource.ts`，迁移 `277_site_media.sql`。
- **边界**：仓库素材不代表任意第三方图像可再分发；新增收益角色素材附独立来源和 CC BY-SA 许可说明。

## 04. 首页真实统计、外部一言与响应节点

- **功能**：公开累计请求、今日 Token、在途、近五分钟活跃登录用户、均价与热门模型；显示最近一次网页请求的应用响应节点。
- **口径**：累计请求包含保留的汇总历史；今日统计按站点时区。在途缺少有效集群快照时保持未知；在线人数不含匿名访客或纯 API 用户。均价为满足最低样本要求的实际 Token 计费加权值，非现金营收或供应商报价。
- **使用**：首页统计定期刷新；一言支持访问和手动换句，外部不可用时回退管理员句池与可翻译离线池。
- **实现**：`frontend/src/features/home/HomeSiteStats.vue`、`useSiteStats.ts`、后端站点统计服务及应用节点响应头链路。
- **边界**：公开聚合可能暴露近似运营规模；网页响应节点不等于另一条模型请求实际使用的 worker。

## 05. 渠道真实健康、历史与公开卡片

- **功能**：从真实用量、可归属的失败记录及允许的主动探针汇总状态、首字、接收速率、缓存率与历史；首页提供专用匿名公开卡片，管理详情仍受权限控制。
- **口径**：失败去重，缺失模型安全读取；状态对应实际模型、来源和时间，不把其他模型的失败贴成探针模型的结果。完整可用率时间窗不会因近期列表只取 TopN 而被截断。
- **细节**：普通接收速率展示可接受满足其他完整窗口/分布门槛的 `timing_uncertain` 样本，但仍标识观测性质；不以旧速率补当前未知，不把普通显示资格当作可信排行资格。
- **实现**：`backend/internal/repository/channel_monitor_health.go`、`channel_monitor_recent_health.go`、`backend/internal/service/channel_monitor_aggregator.go`，前端 `HomeChannelMonitors.vue` 与监控组件。
- **边界**：页面加载正常不代表供应商健康；错误和降级如实保留，完全无样本时显示未知。

## 06. 公开分组选组自动化与主被动探测

- **功能**：管理员先搜索、勾选公开活跃分组，再按组创建或更新监控/广场关联；默认不勾选，不再把空请求当作选择全部。
- **配置**：每组选择 `passive`（完全被动）或 `hybrid`（主动加被动），间隔为 15–3600 的整数秒。未选组和手工配置不被覆盖。
- **被动模式**：只读真实请求、不调度主动任务，手动检测明确拒绝；无真实流量不借历史主动成功显示健康，新建时不配给探测 Key。
- **混合模式**：保留近期真实流量优先与空闲探测；转入主动时解析实际模型并配给所需 Key，已有 Key 不因一般模式切换任意轮换。跨节点配置约每 30 秒同步，未变任务保留计时。
- **一致性**：自动化共享互斥、逐项报告和幂等保护；保留人工价格与显式零值。发现失败保留旧目录，合法空目录可同步为空；取消或失败采用独立清理预算回收本次新配给资源。
- **实现**：`channel_monitor_*`、`frontend/src/views/admin/ChannelMonitorView.vue`，迁移 `281_channel_monitor_probe_mode.sql`。
- **费用**：主动探测属于实际上游请求，可能收费；自动化成功不等于上游全部可用。

## 07. 倍率历史阶梯图与变价明细

- **功能**：管理洞察和用户详情共用基础倍率历史图，列出初始/区间起点、涨价、降价、前后值、差值及准确日期时间/时区。
- **口径**：一个基准点也画水平线；历史被截断时不冒称原始创建价格，无历史只显示当前值。新分组补首个观察点，已有缺历史分组的基准为实际首次记录时间。
- **实现**：`frontend/src/components/user/monitor/MonitorRateHistory.vue`、`frontend/src/utils/monitorRateHistory.ts` 与分组倍率历史读取。
- **边界**：基础倍率轨迹与高峰分时倍率分开，不反推或编造过去的价格。

## 08. 模型广场、白名单与自定义价卡

- **功能**：按分组展示可用模型、协议与价格；支持白名单、模型映射、Token/按次及图像等显式价格配置。
- **使用**：先配置自己的账号与分组，再开放模型目录。专属组和私有组遵守原权限边界，不为展示完整而公开。
- **一致性**：自动目录发现与实际网关白名单保持同一过滤规则；人工渠道及人工价卡受保护，不因一次自动化被清空或改写。
- **实现**：`backend/internal/service/model_plaza_service.go`、`model_pricing_resolver.go`、`frontend/src/views/ModelPlazaView.vue` 与 `components/modelPlaza/`。
- **边界**：价格目录是当前配置的展示，不证明上游内部实际模型身份，也不是可用性承诺。

## 09. Fast/Flex/Ultrafast 策略与协议透传

- **功能**：按可信分组、凭据类型和模型规则处理服务档位；支持放行、过滤、阻断和强制 Ultrafast 等已有策略，区分缺省档位与显式请求。
- **链路**：覆盖 Responses、Chat、WebSocket；Messages 的显式 Ultrafast 只在 OpenAI APIKey 和明确允许的模型/分组规则下透传。Messages 转 Chat 的回退也在最终出站正文应用统一策略，避免绕过强制或阻断规则。
- **计费**：遵循最终出站档位与可观测上游回执的既有合同；有用量的异常流仍保留结算所需档位。支持模型的 Ultrafast 基础价采用独立倍率，再应用分组倍率一次，不叠加 Fast。
- **展示**：费用区显示结算档位；仅当实际各 Token 桶费率匹配时显示 `6×`，自定义价格不冒标。源码中的支持型号/价格属于本版本数据，实际配置必须自行核对供应商现行规则。
- **实现**：`backend/internal/service/openai_gateway_request_body.go`、`openai_gateway_messages.go`、`openai_gateway_messages_chat_fallback.go`、`billing_service.go`；`frontend/src/utils/usageServiceTier.ts`。
- **边界**：结算档位不等于上游已确认，六倍价格不保证六倍速度；OAuth 和其他平台不自动获得 Messages 扩展许可。

## 10. 长上下文阈值与统一价格展示

- **功能**：分组 JSON 价卡可配置 `long_context_input_threshold`，仅指定阈值也能继承基础价格，不必复制整张官价卡。
- **口径**：输入、缓存读取和缓存写入计入上下文阈值；等于阈值保持基础档，严格超过才进入相应高档。具体高档倍率由模型/价卡规则决定，不对所有模型统一硬编码。
- **一致性**：网关收费与广场阶梯使用共享解析结果，手工阈值不被默认目录修正或自动化覆盖。272000 是可配置例子，不把演示站分组 ID/倍率写成所有部署的默认值。
- **实现**：`backend/internal/service/model_pricing_resolver.go`、`frontend/src/components/admin/channel/PricingEntryCard.vue`、分组价卡接口。

## 11. API 密钥夹、分组分类与提示词模板

- **功能**：通过密钥夹和分组分类整理 API Key；按 Key 选择管理员模板或个人提示词配置，保持原账号/分组权限边界。
- **持久化**：模板在启动/首次读取和过期时从持久层刷新，合并并发读取；热快照在短时数据库失败时保留最后成功值，冷启动失败明确报错，不返回伪造空列表。保存后的新版本不会被旧查询覆盖。
- **实现**：`frontend/src/views/user/KeysView.vue`、`frontend/src/views/admin/JailbreakTemplatesView.vue`、设置服务与提示词模板注册表。
- **边界**：模板只是请求配置，不保证模型输出，不代表可以绕过供应商限制或授权边界；已退役集成不会因此重新启用。

## 12. 独立流式计时、接收速率与质量标签

- **功能**：保留原始输出 Token/输出观测时长，同时展示独立请求时长、含等待平均吞吐和质量标签。输出可能含推理 Token，不冒称纯可见文字速率或模型内部解码速度。
- **计时**：HTTP 从应用入口到转发完成；WebSocket 按单轮收帧到终态转发完成，不使用整条连接寿命。输出窗口独立采集，不从总耗时减首字推算旧数据。
- **质量**：完整成功、至少 1 秒、至少 3 个输出事件且跨度至少 250 ms、有效字节分布等条件参与资格判断；相邻 50 ms 桶集中至少 80% 的突发不会当作稳定高速。同步下游背压或消费时钟无法证明到达分布时保守标记 `timing_uncertain`。
- **持久化**：可空且带版本的 `rate_observation` 只记录计时/事件/字节分布，不存请求正文或凭据；贯通各协议结果、SQL/Ent、DTO 与集群最小结算证据。
- **实现**：`backend/internal/pkg/ratemetric/`、`backend/internal/service/rate_observation.go`、`frontend/src/utils/latencyHealth.ts`，迁移 278/279。
- **边界**：旧行缺信息保持未知；写出失败保留应结算用量但观测不完整。展示、特效和可信排行是不同资格，不能互相冒充。

## 13. 高速用量特效与缓存命中率

- **功能**：满足完整窗口/分布条件的普通观测可按原始接收速率触发有限装饰；大于 200 tok/s 为普通高速，达到 300 tok/s 为金色档。
- **细节**：`timing_uncertain` 显示「转发侧观测」；不足 1000 ms 才显示「短窗口（不足1秒）」。1000 ms 及以上仅通过时长条件，仍需满足其余门槛。动效遵守减少动态和手动关闭。
- **缓存率**：缓存读取 ÷（未缓存输入 + 缓存创建 + 缓存读取）；缓存创建参与分母但不算命中，输出不参与。有输入而无命中为 0%，无输入为未知。监控卡另明确自身统计窗口。
- **实现**：`frontend/src/components/admin/usage/UsageTable.vue`、`UsageStatsCards.vue`、`frontend/src/utils/usageCacheRate.ts`、`latencyHealth.ts`。
- **边界**：不封顶、篡改或平滑原始速率来制造效果，不改 Token、费用或历史账单。

## 14. 收益管理、收益公示与个人累计收益

- **功能**：管理员维护分组成本版本并查看收益；用户查看允许公开的收益汇总，个人资料展示累计「总被赚」。
- **计算**：实际计费 − 分组倍率前计费基数 × 已生效成本倍率；收益率使用已知成本的加权计费分母。余额与订阅额度分开，属于计费毛利，不是现金净利润。
- **账务**：在权威结算事务内追加收益事实并冻结成本版本；没有成本配置保持未知而不是零成本。后改成本不自动回算历史，也不改变原扣费、余额、额度或指纹。
- **汇总**：按未完成事实批量领取，不依赖最大 ID 水位，避免乱序提交漏算；maintenance 节点有界聚合。页面可见时刷新，隐藏/卸载取消。
- **权限**：公示只包含公开活跃非独占分组，管理端可读全部及历史分组；非属主节点不能任意写收益事实金额。等成本的特殊公示参考与真实收益明确分开。
- **实现**：`backend/internal/service/site_profit.go`、`site_profit_aggregator.go`、`backend/internal/repository/site_profit_repo.go`、`frontend/src/features/profit/`，迁移 `280_site_profit_ledger.sql`。
- **边界**：公开版不提供演示站成本或任何人工历史补算脚本；收益为负或成本未知时如实显示。

## 15. SubNexus 机器人专用只读接口

- **功能**：ingress 节点提供 `/api/v1/bot/*` 的八类查询：成本、利润、消耗、日志、模型审计、账号状态、渠道状态、模型价格。
- **授权**：管理员创建/列出/撤销独立安装，绑定完整聊天用户/session/conversation 元组和业务数据范围；凭据仅创建时返回，不使用管理员密钥充当机器人令牌。
- **防护**：八段 HMAC-SHA256、正负五分钟时间窗、共享 Redis nonce 防重放与安装限流；跨入口重放拒绝，Redis 不可用失败关闭，不回退各节点内存。
- **只读**：当前仅 `bot:read`，非 GET 操作返回 403；未知 GET 返回 501，未知查询键返回 400。只读事务有时间与响应大小上限，不返回凭据、IP、请求/错误正文或任意运行日志。
- **语义**：账号/渠道为配置状态而非实时健康；价格为显式配置而非最终有效收费；消耗仅覆盖保留明细，未知成本为 null；上游声明模型不证明内部实际身份。
- **实现**：`backend/internal/service/bot.go`、`backend/internal/repository/bot_repo.go`、`backend/internal/handler/bot_handler.go`，迁移 `282_subnexus_bot.sql`。协议详见 `SUBNEXUS_API.md`。
- **边界**：不包含聊天平台插件本体、群推送、定时报表、AI 外发或写操作；API 验证不能代替真人聊天端到端验收。

## 16. Grok 视频内容与安全 CDN 下载

- **功能**：既有视频任务内容端点支持 Range 与完整下载；兼容配置上游的认证 content 路径委托一次公网 HTTPS CDN。
- **防护**：不直接抓取任意任务状态 URL。CDN 新请求不携带 API 密钥/账号覆写头，保留 Range 和签名；拒绝私网、HTTP、非 443 端口、userinfo、片段与后续跳转。
- **错误**：CDN 失败明确返回 `video_content_unavailable`，不据此惩罚文本/图像账号；拒绝起始 HTML/JSON 伪视频成功页，非零 Range 分段不误作完整文件头。
- **实现**：`backend/internal/service/grok_media.go` 及相关 content/relay 测试。
- **边界**：此能力修复取件兼容性，不证明生成视频的比例、解码或供应商内部行为；下载既有任务不应新增生成费用。

## 17. 角色化集群、mTLS 与控制台

- **功能**：按 ingress、controller、worker、maintenance/migrator 等职责启动，提供节点注册、状态、操作和资源控制台。
- **隔离**：纯 worker 不提供管理/用户页面及机器人路由；节点链路使用受控 mTLS，控制与维护职责不能通过普通公网模型请求获得。
- **展示**：按节点汇总已完成用量 RPM/TPM、机器资源、池预算和应用响应节点，缺失/陈旧样本不冒充新鲜健康。
- **实现**：`backend/internal/cluster/`、`frontend/src/views/admin/ops/components/ClusterConsole.vue`、`OpsNodeResources.vue`、`tools/cluster/`。
- **边界**：默认单节点部署不等于完整可靠集群；共享数据库/Redis 单主并不会因增加应用节点自动获得故障转移。

## 18. 并发预算、代理容量与数据库池遥测

- **功能**：从节点注册表同步运行期在途预算和 SQL 池；各非 shadow ingress 独立调和本地 HAProxy，控制器确认全部入口的目标一致性。
- **细节**：代理运行态 `maxconn` 回读并纠正，排队超时按准入配置渲染；使用新鲜 BootID 和目标版本确认，不能只检查磁盘配置。数据库 open/wait_count/wait_ms 为累计遥测，差值需在同一 BootID 内计算。
- **锁**：控制器兼容既有锁域，各入口锁按节点隔离；锁内 SQL 复用同一连接，解锁不确定时淘汰该物理连接，避免泄漏咨询锁。
- **实现**：`backend/internal/cluster/` 中 runtime、proxy、snapshot 与相应容量测试。
- **边界**：配置在途数不等于数据库连接数、真实生成吞吐或供应商兑现容量；隔离并发测试不能认证 WAN/付费模型性能或 N-1 容量。

## 19. 执行准入、耐久恢复与原子结算

- **功能**：在派发前预留本地耐久恢复证据并记录执行；结算保持费用事件幂等和原子事务，重启后可依据权威账务对账。
- **最新修正**：恢复槽预算随运行期并发按 `max(128, 并发 × 4)` 同步；缩容不丢弃现有证据，满槽/读取失败阻止不安全准入。
- **恢复预算**：每轮恢复的金额回放阶段共享最多 5 秒、且不超过创建预算时父剩余时间一半的预算，给后续权威身份/积压读取保留时间；超时义务继续保留，损坏、冲突、权威读取失败或父取消仍失败关闭。
- **结算持锁**：将原扣费与额度更新集中到同一事务提交前，减少持有用户行锁时的网络往返；原金额 SQL、锁顺序、原子性和幂等不变。完成标记与金额证据分开处理，不能用完成标记跳过应回放费用。
- **实现**：`backend/internal/cluster/recovery_reserve.go`、`runtime.go`、`backend/internal/repository/cluster_settlement.go`、`usage_billing_repo.go`，含独立 PostgreSQL 回归。
- **边界**：应用健康 200 不等于准入已恢复；禁止清空 pending/恢复槽伪造健康。应用回滚不删除账务证据，不承诺重启时长流零中断。

## 20. 监控、鉴权、仪表盘与首屏加载优化

- **索引**：迁移 283 为结算 execution_id 查询增加索引，284 为监控健康读取建立覆盖索引；优化不等于所有查询必然使用索引或所有供应商错误消失。
- **鉴权/统计**：合并可合并的数据库读取、批量读取 Redis，独立仪表盘查询有界并行并共享取消；摘要不等慢图表，权限和陈旧标识保留。
- **首屏**：语言资源与首次路由并行加载并共同门控挂载；支付 SDK 延迟分包，避免普通首页提前加载支付依赖。
- **实现**：`frontend/src/main.ts`、`frontend/src/features/home/useHomeMonitors.ts`、仪表盘服务/处理器及监控仓储。
- **边界**：历史小样本提速不是固定延迟保证；本次源码发布不进行公网压测、付费生成或生产重启。
