# 已知限制与验证口径

## 开源发行不等于生产部署

公开仓库导出当前正式定制源码，包括已本地修正但未重新部署演示站的缓存命中率展示。演示站有独立配置、数据和发布节奏。本次只做源码发行，不执行生产迁移、重启或改账。

## 既有测试限制

以下为导出前正式源码记录中的既有状态，**不是本次重新执行得到的通过结论**：

- 前端全量测试曾有 `ChannelStatusV1View.refresh` 两项自动刷新持久化测试失败。
- 后端全量 unit 曾在 `internal/server/api_contract_test.go` 因构造参数夹具缺失而无法编译。
- Windows 缺少 `sh` 会使部分 `TestPgDumper*` 用例失败。
- service 整包测试曾超过既有时间预算；定向通过不能推成整包通过。
- 旧 lint、模块别名诊断及大 chunk/Browserslist 警告可能仍存在。

本次实际验证另写入发行说明/发布核验文档，不用过去记录代替当前测试。CI 如遇这些问题，应按受影响范围核实，不为制造绿色随意降低测试门槛。

## 运行与产品

- 上游账号与模型由部署者自行提供，模型可用性、服务档位、速度和价格取决于实际供应商与配置。
- 服务档位账单不等于上游已确认档位；6 倍价格不等于 6 倍速度。
- 没有完整流区间或准确 Token 的旧记录展示未知，不回填推测结果。
- 多节点可能增加数据库往返成本，不承诺线性扩展、固定吞吐或无中断升级。
- 壁纸折射与动态效果依赖浏览器/GPU，不承诺全设备恒定 60fps、全站无障碍认证或所有浏览器一致。
- 自动外站截图、图标与一言依赖第三方，限流、网络失败与损坏源图都可能发生；支持手动上传回退。
- 新安装不会带入演示站站点内容、账号、价卡、支付或运营配置。

## 发行与升级

- 不使用上游官方镜像冒充定制版；使用源码构建或明确标识的本仓库制品。
- 当前后台在线更新器仍指向上游，**不要用于升级定制版**，否则可能覆盖定制功能。
- 保留的历史部署文档/脚本可能引用上游仓库，优先以 `docs/DEPLOYMENT.md` 为准。
- 第三方素材权限以其各自条款为准，见 [素材说明](ASSETS.md)。

## 首次数据库初始化

历史迁移 265/271 依赖稳定非登录属主 `sub2api_owner`。本公开版 Compose 为全新数据卷接入了前置初始化 SQL；已有卷/外部数据库必须先审查并执行同一脚本。不能靠追加更晚迁移越过前置失败，也不能直接改写历史 SQL。迁移中保留的旧节点角色名不是凭据，但属于必须披露的历史兼容材料。

## 安全

凭据扫描和独立静态审查不是渗透测试或完整安全审计。生产部署还需自行配置 HTTPS、网络隔离、最小权限、备份、恢复演练与访问控制。
